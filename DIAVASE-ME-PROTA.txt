ΣΥΝΤΟΜΗ ΕΚΔΟΧΗ — 4 ΕΝΤΟΛΕΣ
---------------------------
Άνοιξε Git Bash και τρέξε (άλλαξε τη διαδρομή του repo):

  cd /c/Users/$USERNAME/Desktop/ready
  cp -r /c/Users/$USERNAME/Downloads/blog-arakron/* .
  bash install-blog.sh
  git add -A && git commit -m "Blog" && git push


ΤΙ ΚΑΝΕΙ ΤΟ SCRIPT
------------------
1. Backup όλου του repo σε ../ready-backup-<ημερομηνία>
2. Προσθέτει το blog CSS στο assets/site.css
3. site.css?v=10 -> v=11 (cache busting)
4. Βάζει "Blog" σε μενού + footer, 14 σελίδες (GR + EN)
5. +2 URLs στο sitemap.xml
6. Ρυθμίζει clean URLs
7. Σβήνει το προσωρινό blog-css-additions.css

Μπορείς να το τρέξεις πολλές φορές — δεν διπλασιάζει τίποτα.


ΑΝΑΙΡΕΣΗ
--------
Πριν το commit:   git checkout -- . && git clean -fd
Μετά το commit:   git reset --hard HEAD~1
